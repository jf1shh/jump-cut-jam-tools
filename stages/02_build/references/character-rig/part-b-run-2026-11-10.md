# Character rig dry run, Part B: what broke (2026-11-10, n=1)

Full list behind `_config/reference/canon/jam-character-rig-path.md` (which keeps the timed table and the GO/NO-GO line).
Scratch project and logs stayed outside the repo (`~/Projects/rig-scratch`, Rule 7(h)).

## What broke (error, fix, minutes lost)

- **Blender FBX metres read as cm** (A2): the first import was 1.8 cm tall. Fix `import_uniform_scale=100`. Re-importing
  into the same folder silently kept the old scale; a fresh folder was needed. ~2 min.
- **Auto retarget definition fails on Rigify** (A3): `apply_auto_generated_retarget_definition` returned False, 0 chains,
  on the `DEF-` skeleton. Fix: chains by hand, named like Manny's so FUZZY auto-map is 11/11. ~1 min.
- **FBX import renames bones `.` to `_`** (A3): `DEF-spine.001` becomes `DEF-spine_001`; error "Could not create retarget
  chain. Start Bone does not exist". Fix: use the underscore names. <1 min.
- **Commandlet cannot delete or recreate an existing asset** (A3): reuse it and clear it instead. <1 min.
- **Import saved the mesh but not its new Skeleton** (A6): batch said "Unable to retrieve target USkeleton for Animation
  Asset". Fix: save the skeleton explicitly, re-import, redo A3+A5. ~1 min.
- **Batch retarget does not return or save the ABP** (A6): save it by path. A second run made
  `BS_Idle_Walk_Run_Rigify1` despite `overwrite_existing_files=True`.
- **Port 8010 still held after closing an editor** (STALL): the next editor logs "HttpListener unable to bind to
  127.0.0.1:8010" and MCP never answers. Fix: `ss -ltn | rg 8010` must be empty before launch; keep ONE editor open
  for all play tests. ~31 min lost (with the GPU-gate wait).
- **Physics assets missing** for both test meshes (LoadErrors on load). Not the cause of the bad play; not fixed.
- **Not fixed: retargeted animation breaks path A.** Rest pose is right, so the mesh and skeleton import are fine; one
  retargeted clip alone sends the mesh out of view. Suspect: root/pelvis translation scale against the x100 import
  (UNTESTED). The ABP also warns "Control Rig - Hierarchy discrepancy for bone 'root'" (Rigify has no `root` bone), and
  `apply_auto_fbik` made 0 goals (FK only, no foot IK).
- **Not fixed: Manny animation breaks path B.** The 26-bone mesh on `SK_Mannequin` imports with no error but faces
  90 deg off and goes invisible under `ABP_Unarmed`. The video claim "mannequin skeleton accepted without retarget" is
  half true: accepted, yes; plays, no.
