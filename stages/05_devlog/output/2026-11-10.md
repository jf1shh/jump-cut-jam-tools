## One thing that surprised us
In mock 10, the "level fixed" edits never reached disk. `save_assets` answered "All files are already saved"
because the editor does not see actor changes made over MCP as dirty, so the shipped build still held the old
level. A person playing the packaged build is what caught it. Now a script (`scripts/force_save_level.py`) must
print `VERIFIED` before every package step. Source: `stages/00_prep/output/mock-jam-findings-10.md`, "Playable gate failure".
