## The performance find

The same Scene 1 that draws 1,793 primitives and no shadow passes in the editor drew 103,732 primitives and 18 shadow
draws on the handheld. The Windows build was cooked for the older shader model only (SM5), so Nanite was off and
every mesh fell back to a heavy version. The next test build cooks for SM6 with SM5 as a fallback, plus a lighter
preset for the handheld's integrated GPU. A desktop check of build 71 (72 draw calls, 2.96 ms of GPU time a frame,
nearly half of it upscaling) pointed at the handheld's integrated GPU as the limit.

A Claude Fable "game director" review scored build 65 at 17 out of 35: Ambition 3, Theme 3, Fun 2, Gameplay 3,

## One thing that surprised us

Our own tests never showed the CLOSE stamp. At first that looked like the tests' fault: they only dodged in the PERFECT
band (0.42-0.59 s) or the WIDE band (2.56 s and up). The handheld's next run swept the middle, 0.75 to 2.2 seconds, and
CLOSE still never fired. So it is a real bug in the game, and it is on the lead's list.
