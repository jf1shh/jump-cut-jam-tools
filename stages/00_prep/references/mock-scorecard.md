# Mock jam scorecard

One row per mock jam, so mocks can be compared and the gates judged: did they catch what the owner
caught? Filled by `scripts/mock_scorecard.py` from the mock's evidence (owner "file them", 2026-11-08).

Refresh a row (hand-entered facts live in `stages/00_prep/output/mock-scorecard-N.json`):

```bash
MOCK=~/Projects/megajam-mock11-kept   # the mock's own project folder; ~/Projects/megajam-mock holds the newest mock
python3 -I scripts/mock_scorecard.py --mock 11 --data stages/00_prep/output/mock-scorecard-11.json \
  --findings stages/00_prep/output/mock-jam-findings-11.md --repo $MOCK \
  --step-shots $MOCK/work/step-shots --playtest $MOCK/work/vp_r16 --assets $MOCK/work/assets \
  --butler-log $MOCK/work/push.log --agent-gate $MOCK/work/agent-gate.txt --update stages/00_prep/references/mock-scorecard.md
```

## Columns

| Column | Meaning | Source |
|---|---|---|
| Kickoff to first packaged | Kickoff (findings "Start:") to the first packaged build pushed, playable or not | butler log, git log, or hand-entered |
| Kickoff to first playable packaged | Same, but the first packaged build a person can actually play | hand-entered (a human or agent must have played it) |
| Step shots | pass = every verdict starts with OK/PASS/GOOD (write verdicts that way); FAIL/FAILED/BAD/BROKEN = fail; anything else = n/a | `steps.md` |
| Asset previews | pass = every `preview.json` has `ok: true` | `preview.json` files |
| Playtest | What `visual_playtest.py verify` decided on the filled-in `checklist.md`. With no checklist only auto results exist, shown as `pass (auto only)`, fail or n/a, never as a human pass | `results.json`, `checklist.md` |
| Clip motion | the playtest "motion" item (idle view holds still) | `results.json` |
| Agent playtester | pass = `agent_playtest_cli.py gate` printed GATE PASS | saved gate output |
| Real props / primitives | Generated or sourced props in the level / engine primitives (cubes, spheres, cones) | hand-entered count |
| Won by real play | The agent reached WIN by real play, not autopilot | hand-entered |
| Bugs gates missed | Bugs the owner found that no gate flagged | hand-entered list |
| Overran | Work went past the hard stop | hard stop vs last commit, or hand-entered |

A gate shows `n/a` when it did not exist or was not run for that mock. `n/a` is never a pass.
