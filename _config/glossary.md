# Glossary

> Canonical sources: `AGENTS.md`, `RULES.md`, `PLAN.md`. Terms only; no rules restated.

| Term | Meaning |
|---|---|
| Jam / window | The 2026 Epic AI MegaJam contest window, Nov 12 00:00 ET to Nov 15 8:59 PM ET |
| Rule 7(h) | No gameplay, levels or art before the window opens; pre-jam work is tools, plans and research |
| Mock jam (mock N) | Full rehearsal of the jam in a separate project; only findings and tool fixes come back here (`stages/00_prep/output/`) |
| Glass Box | The public dev log of how the entry was made, written with `scripts/gen_devlog.py` (`stages/05_devlog/`) |
| Gate build | One of the four scheduled builds in `PLAN.md` Phase 1; master moves only at a gate |
| `jam-integration` | Integration branch agents merge into during the window |
| Lead agent | The single agent that calls Unreal MCP (port 8010) |
| Hub | The owner-facing Claude session that routes tickets and approves routine asks |
| Legion | Legion Go S (Windows 11), the packaging and capture box (`ssh <device-host>`) |
| Diversion | Version control for the UE project (`~/Projects/megajam-game`); GitHub holds code and docs |
| Canon | `_config/reference/canon/` notes (front-matter tiers `tested`, `epic`, `community`) ingested into Nexus `unreal_canon` |
| ICM | Interpretable Context Methodology: Layer 0 `IDENTITY.md`, 1 `CONTEXT.md`, 2 stage `CONTEXT.md`, 3 `_config/` and `references/`, 4 `output/` |
