# Feature-slice brief — [slice name]

One slice, one brief, under ~2 hours of work. If it doesn't fit on this much, split it.

- **One-paragraph brief:** what this slice adds, in plain language.
- **Done-test:** the single action that proves it works, phrased as press/do X → Y happens
  (e.g. "press E near a door → it opens with sound"). If you can't write a done-test, the slice is
  too vague to start.
- **Touches:** files/systems this slice changes (keeps file ownership clear if more than one agent
  is working — see AGENTS.md's one-MCP-caller-at-a-time rule for anything touching the open level).
- **Playtest note:** your 2-minute playtest result, written right after the done-test passes, before
  starting the next slice. One or two sentences — did it feel like the one-pager said it would?
- **Commit:** the commit hash/message once this slice lands.
