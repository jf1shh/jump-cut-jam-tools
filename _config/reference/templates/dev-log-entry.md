# Dev log entry — [date]

15 minutes, every night, built from that day's commits/screenshots/notes. Posts to the itch.io devlog
(Rule 10, Glass Box). The dev-log-tooling script (Week 2) should be able to draft most of this from
git log + the day's screenshots — edit, don't write from scratch.

- **What shipped today:** 2-4 bullets, plain language, screenshots inline.
- **What's next:** tomorrow's top slice or two.
- **One thing that surprised us:** a genuine "huh, didn't expect that" — this is what judges and
  readers actually remember from dev logs, not the feature list.
- **AI disclosure:** which models/tools did what today (context only for scoring, Rule 9, but Epic
  may ask for the pre-jam declaration trail, Rule 7(h)).
- **Build/version:** build number or commit tag this entry corresponds to.
