# MegaJam canon — searchable index

**Jam day: read `_config/reference/canon/jam-top-lessons.md` first** (one screen, the 15 rules from mocks 10-15 that most change our odds).

Everything this project knows, in one place. `grep -i "<topic>" _config/CANON.md` to find the
right file fast, or search the grep patterns column directly across the repo. This indexes
*data and documentation* (plans, rules, research, findings, reference, logs). For source-code
navigation (symbols, call graphs), use `graft` instead (`graft/INDEX.md`, `graft ask "<task>"`)
— that's a separate, complementary tool scoped to code, not docs.

Keep this file updated whenever a doc is added, renamed, or superseded — it decays fast
otherwise. One line per file: path, one-line content summary, and status if not current.
